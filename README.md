# Mahila-Shakti Unnati Using GenAI

## Project Overview

Mahila-Shakti Unnati is a digital micro-finance Android application developed to help rural Women Self-Help Groups (SHGs) manage savings, loans, repayments, and group capital efficiently. The application replaces traditional paper-based registers with a secure digital ledger system, reducing manual calculation errors and improving transparency within SHGs.

The app works completely offline using Room Database and provides easy financial tracking for SHG leaders through a simple and user-friendly interface.

---

# Features

* Member management system
* Weekly savings entry tracking
* Paid/Pending savings status
* Loan management system
* Simple interest calculation
* Loan repayment tracking
* Loan block rule for unpaid loans
* Group capital auto-calculation
* WhatsApp summary export
* Offline-first functionality
* Responsive and easy-to-use UI
